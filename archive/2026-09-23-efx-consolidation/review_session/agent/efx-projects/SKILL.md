## 5. Router call shape (`00_EFX_Router.json`) and envelope
Inputs: `fn` (alias name), `args[]` (positional, **without** actor), `actor?`, `idempotencyKey?` (built: cached reply for the same key), `treatAlreadyClosedAsSuccess?` (default true).
Transport: `POST https://script.googleapis.com/v1/scripts/<<EFX_SCRIPT_ID>>:run` with the Google Service Account credential impersonating `efx-bot@team-group.com`, `devMode:false`.
Alias envelope: `{ ok:true, apiVersion, requestId:'REQ-…', result:{…} }` or `{ ok:false, apiVersion, requestId, error:{ code, message, fields?, upstream?, principal? } }`.
The Router **flattens** success to the result (+`fn`, `tookMs`) and **throws** on failure: `EFX <CODE>: <message> [fn=…, requestId=…]` — except `E_ALREADY_CLOSED`, which becomes `{ok:true, alreadyClosed:true}` unless `treatAlreadyClosedAsSuccess:false`.
`requestId` is persisted in the Forms Raw Log (`Kind = alias`) for every failure and every successful mutating call — quote it.
